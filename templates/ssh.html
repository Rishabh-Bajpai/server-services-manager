About

Manages ~/.ssh/authorized_keys. The file is written atomically (tempfile + rename) with mode 0600. A backup is saved as authorized_keys.bak before each removal. Refusing to remove the last remaining key is the default — pass confirm_last to override (you may lock yourself out).

Add SSH key

Paste the public key line (starts with the algorithm, e.g. ssh-ed25519). Options like from="..." are accepted.

Remove key?

This will remove the key.

This is the only authorized key. Removing it may lock you out of the box. Only proceed if you have another way in (console, password auth, another key).
